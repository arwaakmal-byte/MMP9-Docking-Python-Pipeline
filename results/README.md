# Results

This folder is a placeholder. The actual result CSVs produced by this pipeline live in the project's persistent storage (`PROJECT_DIR`, e.g. a mounted Google Drive path) rather than in this repo, since they're regenerated by running the scripts and can be large.

Files produced, in the order they're created:

- `MMP9_composite_ranking_full.csv` — from the upstream QSAR pipeline (not part of this repo).
- `MMP9_docking_results.csv` — from `scripts/04_docking.py`.
- `MMP9_zinc_interaction_check.csv` — from `scripts/06_zinc_interaction_check.py`.
- `MMP9_FINAL_lead_selection.csv` — from `scripts/07_final_lead_selection.py`, the final deliverable of this pipeline.

If you want these tracked in version control for a specific run, copy them in here and remove the corresponding line from `.gitignore`.
